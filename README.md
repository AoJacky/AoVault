# AoVault 工作区说明（README）

> 这是一个 Obsidian 笔记库（vault），同时承载个人知识沉淀与日常工作管理两大类内容。本文介绍整个工作区的结构与使用方式。

## 定位

AoVault 是一个多用途工作区，涵盖两块核心内容：

- **工作**：与开发工作相关的笔记（Bug、需求、功能、优化），并与 Azure DevOps 工作项联动。
- **知识**：长期积累的个人知识库，涉及技术、读书、生活等主题。

此外还包含 Obsidian Copilot 的对话记录、自定义提示词与绘图素材。

## 目录结构

| 顶层文件夹 | 用途 | 说明 |
| ---------- | ---- | ---- |
| `工作/` | 工作管理笔记 | 按工作项类型分子目录，见下方详述 |
| `知识库/` | 个人知识库 | 分类存放 200 篇笔记，含索引与模板 |
| `copilot/` | Obsidian Copilot 数据 | 对话记录、自定义提示词、内置技能 |
| `Excalidraw/` | Excalidraw 绘图 | 白板绘图文件 |
| `Pasted image *.png` | 粘贴图片 | 编辑时粘贴生成的图片 |

### 工作文件夹

`工作/` 内按工作项性质分目录：

| 子目录 | 内容 | 示例 |
| ------ | ---- | ---- |
| `Bug/` | 缺陷跟踪笔记 | E 550-EP 编码器自动识别失败（Bug 887502） |
| `Feature/` | 功能开发笔记 | EnDat3 编码器 IP 移植与设计（含 Design / Requirements 子目录） |
| `Optimize/` | 优化改进笔记 | PR 合并中解决冲突的方法 |
| `Others/` | 其他工作随笔 | 工作相关提醒支持 |
| `PDA/` | PDA 相关笔记 | PDA 使用方法 |
| `Requirements/` | 需求笔记 | E 550/E 530 编码器自动识别（Requirement 896437） |

这一类笔记通常以 `[工作项标题](Azure DevOps 链接)` 开头，直接链接到 Azure DevOps 工作项，便于在工作区与云端之间跳转。

### 知识库文件夹

`知识库/` 按主题分类（200 篇），详见工作区主入口 [[知识库-索引]]：

- **技术**：`电机控制/`（59 篇）、`嵌入式/`（52 篇）、`硬件/`（14 篇）、`工具/`（7 篇）、`AI/`（预留）
- **知识**：`生活/`（33 篇）、`读书/`（12 篇）、`其他/`（11 篇）、`健康/`（6 篇）、`科技/`（5 篇）、`English/`（1 篇）
- **入口**：[[知识库-索引]]（全部笔记的 MOC）、[[知识库-模板]]（新建笔记模板）

### Copilot 文件夹

`copilot/` 存放 Obsidian Copilot 相关的配置与产出：

| 子目录 | 内容 |
| ------ | ---- |
| `copilot-conversations/` | 与 Copilot 的历史对话记录 |
| `copilot-custom-prompts/` | 自定义提示词（摘要、翻译、改写、剪藏等） |
| `skills/` | 内置/自定义技能（网页搜索、PDF 阅读、知识整理等） |

## 使用约定

- **工作笔记**：新建前先看 `工作/` 下是否有对应分类目录；引用工作项时用格式 `[标题](Azure DevOps URL)`。
- **知识笔记**：复制 [[知识库-模板]] 的结构新建，放入 `知识库/` 对应分类；frontmatter 统一含 `title`、`date`、`tags`、`source`。
- **知识导航**：从 [[知识库-索引]] 进入，新增/删除笔记后同步更新该索引。
- **去重**：保持内容唯一，重复笔记仅保留内容更完整的版本，并清理索引中的失效链接。
