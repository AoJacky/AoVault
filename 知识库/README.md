# 知识库说明（README）

> 这是个人知识库的说明文件，介绍组织结构、使用方式与维护约定。

## 导航入口

- [[知识库-索引]] — 全部笔记的分类索引入口（MOC）
- [[知识库-模板]] — 新建笔记的标准模板

建议始终从**索引**进入：`知识库/知识库-索引.md` 按分类列出所有笔记，带 wikilink 可直接跳转。

## 使用约定

- **新建笔记**：复制 [[知识库-模板]] 的结构（frontmatter + 摘要 + 原文要点 + 个人想法 + 原文链接），放入对应分类文件夹。
- **frontmatter** 统一包含 `title`、`date`、`tags`、`source` 四个字段；其中 `tags` 至少包含 `知识库` 和分类名。
- **维护索引**：新增或删除笔记后，同步更新 [[知识库-索引]]，避免失效链接。
- **去重**：同一主题只保留一份笔记；发现重复时保留内容更完整的版本。
