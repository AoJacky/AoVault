# PCB设计中焊盘的种类及设计标准

## 一、常见焊盘

| 类型 | 特点 |
|------|------|
| **方形焊盘** | 元器件大而少、导线简单时采用，手工自制PCB易实现 |
| **圆形焊盘** | 广泛用于元件规则排列的单双面板，密度允许时焊盘可大些 |
| **岛形焊盘** | 焊盘与焊盘间连线合为一体，常用于立式不规则排列安装 |
| **多边形焊盘** | 区别外径接近而孔径不同的焊盘，便于加工和装配 |
| **椭圆形焊盘** | 足够面积增强抗剥能力，常用于双列直插式器件 |
| **开口形焊盘** | 保证波峰焊后手工补焊的焊盘孔不被焊锡封死 |

## 二、特殊焊盘

### 梅花焊盘
用于大的过孔接地位置：
1. 固定孔需金属化和GND相连，全金属化孔回流焊时易堵孔
2. 梅花孔焊盘不管应力如何变化，均能保证良好接地

### 十字花焊盘（热焊盘/热风焊盘）
减少焊盘向外散热，防止虚焊或PCB起皮：
1. 焊盘为地线时，减少连接地线面积，减慢散热，方便焊接
2. 机器贴片回流焊时，防止PCB起皮

### 泪滴焊盘
焊盘连接走线较细时采用，防止焊盘起皮、走线断开，常用在高频电路中

## 三、焊盘设计标准

### 形状和尺寸
1. 焊盘单边最小≥0.25mm，直径最大≤元件孔径3倍
2. 两个焊盘边缘间距>0.4mm
3. 布线较密时推荐椭圆形/长圆形连接盘；单面板焊盘直径≥1.6mm
4. 插件元器件单面连接盘应用铜箔完全包覆；双面板最小应补泪滴
5. 机插零件沿弯脚方向设计滴水焊盘
6. 大面积铜皮上焊盘用菊花状焊盘，防虚焊

### 过孔大小
- 焊盘内孔一般≥0.6mm（<0.6mm开模冲孔不易加工）
- 内孔直径 = 金属引脚直径 + 0.2mm

### 可靠性设计要点
1. **对称性**：两端焊盘必须对称，保证熔融焊锡表面张力平衡
2. **焊盘间距**：过大过小都会引起焊接缺陷
3. **焊盘剩余尺寸**：搭接后必须保证焊点能形成弯月面
4. **焊盘宽度**：应与元件端头或引脚宽度基本一致

### 制造工艺要求
1. 贴片元器件两端无插装元器件的应加测试点（≥1.8mm）
2. 脚间距密集的IC脚焊盘需加测试焊盘
3. 焊盘间距<0.4mm须铺白油减少连焊
4. 贴片元件两端及末端应设计引锡（宽0.5mm，长2-3mm）
5. 单面板手焊元件需开走锡槽
6. 导电橡胶按键间距与尺寸应与实际相符，PCB设计为金手指
7. 焊盘大小尺寸与间距要与贴片元件尺寸基本一致
