# IGBT基础与运用知识

## IGBT概述

IGBT（绝缘栅双极型晶体管）= MOSFET（输入级）+ PNP晶体管（输出级）复合器件：
- 兼有MOSFET驱动功率小、开关速度快（控制和响应）
- 兼有双极型器件饱和压降低、容量大（功率级耐用）
- 频率特性介于MOSFET与功率晶体管之间，可工作于几十kHz

## 开关特性

### 开通过程（5阶段）

| 阶段 | 说明 |
|------|------|
| **第1阶段** | 栅极电流对C_GE充电，V_GE上升到开启阈值V_GE(th)，集电极无电流（死区时间） |
| **第2阶段** | 栅极电流对C_GE和C_GC充电，集电极电流增加至最大负载电流I_C，V_GE达到米勒平台电压 |
| **第3阶段** | 栅极电流对C_GE和C_GC充电，V_GE不变（米勒平台），V_CE变化很快 |
| **第4阶段** | 栅极电流对C_GE和C_GC充电，V_CE缓慢变化至稳态，米勒电容随电压减小而增大 |
| **第5阶段** | 栅极电流对C_GE充电，V_GE继续上升，IGBT完全打开 |

### 关断过程

漏极电流分两段：
1. 第一段：按MOS管关断特性
2. 第二段：MOSFET关断后，PNP晶体管存储电荷难释放，造成较长尾部电流（tail current）

关键时间参数：关断时间T_off、下降时间T_f、存储时间t_d(off)+t_rv

## 电容参数

| 参数 | 定义 |
|------|------|
| C_GE | 栅极-发射极电容 |
| C_CE | 集电极-发射极电容 |
| C_GC | 栅极-集电极电容（米勒电容） |
| C_ies = C_GE + C_GC | 输入电容 |
| C_res = C_GC | 反向传输电容 |
| C_oes = C_GC + C_CE | 输出电容 |

## 栅极电阻设计

**栅极电阻值小**：充放电快，减小开关时间和损耗，避免dv/dt误导通；但杂散电感产生大电压尖峰，易寄生振荡

**栅极电阻值大**：充放电慢，开关时间和损耗增大

**驱动电压**：
- 开通：15V±10%（完全饱和、开关损耗最小）；<12V通态损耗加大；>20V难以实现过流及短路保护
- 关断偏压：-5~-15V（噪声下仍可关断，减小关断损耗），最佳-8~-10V

## 栅极驱动PCB布线要点

- 核心问题：降低寄生电感
- 驱动至栅极引线加粗，寄生电感减至最低
- 控制板与栅极驱动电路防止功率电路和控制电路间电感耦合
- 不能直接连接时用双股绞线（<3cm）或带状线、同轴线

## 栅极保护

- 采用TVS等栅极箝位保护电路，放置于靠近IGBT模块栅极和发射极控制端子附近

## 死区时间

- 人为加入上下桥臂同时关断时间，保证驱动安全
- 死区时间大→可靠但波形失真、效率降低
- 死区时间小→波形好但可靠性降低
- 典型值3μs以上
- 注意：环境温度对t_off影响大，栅极电阻也影响关断时间
