# 为什么Byte范围是-128到127——原码反码补码详解

> 从符号位出发，详解原码→反码→补码的演进逻辑，以及模和补数概念解释byte范围。

## 摘要

strongerHuang详解计算机二进制编码：符号位引入→原码运算错误→反码修正（循环进位）→补码（模+补数），最终解释byte范围-128~127。

## 原文要点

### 1. 符号位
- 最高位0为正，1为负
- 解决计算机如何表示负数

### 2. 原码
- -2 = 1010（最高位符号位）
- 问题：4-2 = 0100+1010 = 1110 = -6 ❌
- 根本原因：相反数相加不等于0

### 3. 反码
- 正数按位取反得负数：2=0010 → -2=1101
- 运算：4-2 = 0100+1101 = 0001 = 1 ❌
- **修正方法**：符号位有进位时，进位加到结果最后一位
  - 4-2 = 0001+1 = 0010 = 2 ✅
  - -4-2 = 1000+1 = 1001(反码) = 1110 = -6 ✅
- 缺点：需额外修正步骤，且+0和-0问题未解决

### 4. 模与补数
- **模**：计量系统的计数范围（如12小时制模=12）
- **补数**：|A|+|B|=M时，A的补数是B
- **核心定理**：有模系统中，减去一个数=加上它的补数
  - 时钟：2-1 = 2+11 = 13 mod 12 = 1

### 5. 补码与byte范围
- 4位二进制模=16（2⁴=16）
- 补码：正数不变，负数=模-|负数|
- 8位byte：模=256
  - 00000000~01111111 = 0~127
  - 10000000 = 128 → 补数-128
  - 11111111 = 255 → 补数-1
  - 范围：-128~127，共256个数
