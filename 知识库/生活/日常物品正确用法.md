# 日常物品的正确用法

> 3300万点击的教学视频引发网友热议：原来平时没注意到的设计全部都有用！

| 物品 | 正确用法 |
|------|---------|
| 卷尺 | 背面标了卷尺自身长度，贴墙量时加上即可；前端勾子可代替笔画线 |
| 奶茶扣 | 用来折叠固定杯口，不是装饰 |
| 易拉罐拉环 | 翻转后可固定吸管 |
| 削皮刀 | 可以来回刮皮（双面） |
| 平面吸盘 | 用于平面下水道/洗手盆，不是通马桶的 |
| 气泵型吸盘 | 才是通马桶用的 |
| 护颈枕 | 厚的一面朝前放 |
| 浴袍腰带 | 放前面系更紧，不会掉 |
| 意粉包装袋 | 不用剪刀即可撕开 |
| 意粉勺中间的孔 | 一孔=一人份 |
| 电饭锅盖/保温杯盖 | 可以插在把手上立放 |
| 行李箱扣带 | 正确扣法（见图片） |
| 麦当劳汉堡盒孔 | 不是透气的（固定用） |
| 薯条盒 | 可以折叠成小托盘 |
| 饮料杯盖 | 翻过来当杯垫 |
| 巧克力 | 往内掰最省事 |
| 7-11饭团 | 先撕中间纸，再从两边取塑料膜；海苔包外面是防吸水变不脆 |
| 酸奶吸管 | 拉出后要拧一拧固定 |
| 酸奶盒 | 展开死角边吸边挤压可喝完 |
| 火腿肠 | 牙签穿过金属环底部扭一扭即可剥开 |
| 倒果汁/牛奶 | 换个角度（口朝上/朝下）倒不会洒 |
| 裁纸刀 | 棱线是用来掰开获取新刀口的 |
| 订书机底部金属片 | 可翻转区分永久装订/临时装订 |
| 超市铁丝封口 | 不用硬抠，有正确拆法 |
| 发夹 | 波浪纹朝下才不会掉 |
| 洗衣机洗衣槽 | 可取下来清洗 |
