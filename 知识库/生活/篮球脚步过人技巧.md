# 练好脚步，简单过人

> 一个简单实用的篮球过人动作，核心在脚步上，可接多种变向。

## 动作节奏

**Boom → One Two → Crossover**

即：**下球 → 脚步 → 变向**

- 普通crossover：出脚 → 下球 → 变向
- 这个动作：下球时脚步，然后变向

关键区别：**下球的同时开始脚步动作**。

## 可接的后续动作

1. **再接一个变向**（双重变向）
2. **背后变向**
3. **拉回急停** — 有效变向+急停，野球场很实用
4. **胯下变向**

核心：**先把脚步动作练好**，手上动作自然流畅。
