# 象棋布局

> 象棋开局遵循三大原则，按风格分为四大类型。

## 摘要

本文整理了象棋布局阶段的核心框架：三大基本原则和四种进攻/稳健类型。三大原则指导开局阶段的行棋方向——出动大子、左右均衡、抢占要道；四大类型则按攻击节奏和风格，从急攻到散手形成谱系，帮助棋手根据自身风格选择开局策略。

## 原文要点

### 一、三大原则

| 原则 | 说明 |
|------|------|
| 出动大子 | 优先出动车、马、炮等大子；车又分**直车**（进攻型）和**横车**两种出动方式 |
| 左右均衡 | 两侧子力协调出动，避免一侧重、一侧空 |
| 抢占要道 | 控制棋盘关键线路和位置，掌握主动权 |

### 二、四大类型

| 类型 | 风格 | 代表开局 |
|------|------|----------|
| 急攻型 | 进攻 | 急进中兵、五九炮 |
| 缓攻型 | 进攻 | 五七炮 |
| 灵活型 | 稳健 | 仙人指路 |
| 散手型 | 稳健 | — |
