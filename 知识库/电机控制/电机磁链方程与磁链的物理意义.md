# 电机磁链方程与磁链的物理意义

> 磁链是电感回路"磁状态"的度量（等于每匝磁通乘匝数的累加）；在电机里它既是电压的因（法拉第定律），又是转矩的源（$\psi \times i$），是电与磁、电与机电能量转换之间的枢纽。

## 摘要

磁链（flux linkage）定义为每匝磁通乘以匝数的累加，即 $\psi = \sum_k N_k \Phi_k$，单位 Wb·匝（= V·s）。它之所以被单独定义为 $N\Phi$ 而非磁通 $\Phi$，是因为 $N$ 匝串联线圈的感应电动势相加，法拉第定律给出 $e = -d(N\Phi)/dt$，$N\Phi$ 自然成为刻画回路磁耦合强弱的量。物理上磁链是电感的"状态量"，与机械动量 $p=mv$ 高度类比（$\psi=Li$，$v=d\psi/dt$，储能 $\frac{\psi^2}{2L}$ 对应 $\frac{p^2}{2m}$）。在电机模型中，磁链由电压积分得到（$\psi=\int(v-Ri)dt$），又通过 $d\psi/dt$ 决定电压、通过 $\psi \times i$ 决定转矩，因此它是矢量控制（FOC）、弱磁、无感观测的核心对象。

## 原文要点

### 1. 物理定义：为什么是 $N\Phi$ 而不是 $\Phi$

单匝线圈感应电动势即法拉第定律：

$$e = -\frac{d\Phi}{dt}$$

一个 $N$ 匝线圈，每匝串接、穿过相同磁通 $\Phi$，感应电动势相加：

$$e = -N\frac{d\Phi}{dt} = -\frac{d(N\Phi)}{dt}$$

于是自然地把 $N\Phi$ 打包成一个量——**磁链**：

$$\psi = N\Phi\quad[\text{Wb·匝}] = [\text{V·s}]$$

推广到分布绕组：$\psi = \sum_k N_k \Phi_k$，即"总磁通按各匝有效匝数加权求和"。

> 关键点：$\Phi$ 是磁通，$\psi$ 是"磁通 × 匝数"。同样的磁通，匝数越多，耦合越强、能感应出的电压越大。

### 2. 三个形象类比

| 电域 | 机械域 | 关系式 | 储能 |
|---|---|---|---|
| 电荷 $Q = CV$ | 位移 | 电容 | $\frac12 CV^2$ |
| 电流 $i = dQ/dt$ | 速度 | | |
| **磁链 $\psi = L\,i$** | **动量 $p = m\,v$** | 电感 | $\frac12 Li^2 = \frac{\psi^2}{2L}$ |
| 电压 $v = d\psi/dt$ | 力 $F = dp/dt$ | | |

**最有力的类比：磁链 ≈ 动量。**

- 动量 $p=mv$：力是动量的变化率 $F=dp/dt$，储能 $\frac{p^2}{2m}$；
- 磁链 $\psi=Li$：电压是磁链的变化率 $v=d\psi/dt$，储能 $\frac{\psi^2}{2L}$。

因此电感像一个"电学飞轮"：加电压则磁链（动量）积累，短路则电流（速度）靠磁链惯性维持。**磁链就是电流回路的"运动量"。**

### 3. 电机里的磁链方程

**（1）abc 三相（含机端电阻）：**

$$v_{abc} = R\,i_{abc} + \frac{d\psi_{abc}}{dt}$$

移项积分就是磁链的"测量式"：

$$\psi_{abc}(t) = \int\big(v_{abc} - R\,i_{abc}\big)\,dt$$

这说明磁链是一个可积分得到的**状态量**（像电荷、像动量），也是它能被"观测器"估计的根本原因。

**（2）转到旋转 dq 坐标系（同步速 $\omega$）：**

$$v_d = R\,i_d + \frac{d\psi_d}{dt} - \omega\psi_q,\qquad
v_q = R\,i_q + \frac{d\psi_q}{dt} + \omega\psi_d$$

对永磁同步电机（PMSM）：

$$\psi_d = L_d i_d + \psi_f,\qquad \psi_q = L_q i_q$$

其中 $\psi_f$ 为**永磁体磁链**（转子永磁体提供、恒定）。$\omega\psi$ 项即**反电动势/旋转电动势**：磁链在旋转坐标系下随转子转动而产生的电压。

**（3）转矩（机电转换的出口）：**

$$T_e = \frac{3}{2}\,p\,\big(\psi_d i_q - \psi_q i_d\big)
= \frac{3}{2}\,p\,\big(\psi_f i_q + (L_d-L_q)\,i_d i_q\big)$$

转矩正比于**磁链矢量与电流矢量的叉积**——磁链提供"磁场"，电流提供"载流导体"，二者叉乘产生力。没有磁链就没有转矩。

### 4. 为什么磁链如此重要

1. **它是电机的状态量（最核心）**：电流、位置会突变，但磁链连续（$\propto$ 积分）。建模、观测、控制都拿它当状态变量；无感控制里的"磁链观测器""滑模观测器"估计的就是它，再由它反推转子位置与转速。
2. **它连接电压与电流（电磁对偶）**：$d\psi/dt$ 是电感上的电压降，$L=\psi/i$（线性时），自然描述**磁饱和**（$\psi$ 与 $i$ 非线性）。
3. **它产生反电动势，限制最高转速**：永磁机空载时 $e \propto \omega\psi_f$，转速越高反电动势越大，最终撞上母线电压上限。
4. **它是弱磁控制的物理对象**：电压极限 $|v| \le V_{max}$ 意味着高速时必须**减小磁链幅值**才能继续升速——即注入负 $i_d$ 抵消 $\psi_f$。"弱磁"就是"主动降低磁链"。
5. **它是矢量控制（FOC）的坐标基准**：FOC 的本质是把磁链矢量 $\psi_s$ 定向到 d 轴，再分别控制其**幅值**（励磁）与**正交分量**（转矩）。FOC 控制的就是磁链矢量本身。
6. **它统一了机电能量转换**：电感储能 $\frac{\psi^2}{2L}$ 类比动能 $\frac{p^2}{2m}$，机电能量转换本质是磁链（磁场的动量）与电流之间的耦合做功。

### 5. 一张图总结

```text
        电压 v ──► [ R i + dψ/dt ] ──► 电流 i
                          ▲
                          │ 磁链 ψ = ∫(v-Ri)dt
                          │ (状态量, 类比动量)
                          ▼
        转矩 T ∝ p·(ψ × i)  ──► 转速 ω ──► 反电动势 ωψ  ──回馈到电压
```

- 磁链是**闭环中心**：由电压积分而来，又决定反电动势和转矩；
- 一切高级控制（FOC、弱磁、无感）归根结底都是在**管理磁链矢量 $\psi$**。

## 个人想法

q 轴磁链在 d 轴上的耦合项是永远负号，因为磁链旋转过程中，既产生动生电动势，也产生感生电动势，总体而言，反电动势超前磁链 90°（电压磁链的微分），但感生电动势的方向由微分算子决定，而动生电动势只与运动方向相关，需要结合图形理解并用符号约束。

反电动势的相位超前磁链 90°，表达超前的方式有两种方式，一种由微分方程表达，一种由空间相位关系表达。感生电动势只发生幅值变化，可以由微分方程表达，动生电动势幅值不变，方向变化，因此由空间相位关系表达。
