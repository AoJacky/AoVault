# 永磁同步电机控制策略：MTPA、弱磁与MTPV

> 永磁同步电机在不同转速区间的最优电流控制策略：恒转矩区MTPA、恒功率区弱磁控制、高速区MTPV。

## 核心概念

### 电压极限与电流极限

- 逆变器输出电压受直流母线电压限制，定子电压矢量幅值与电角频率（转速）相关
- 逆变器输出电流受容量限制，定子电流有极限值
- **电流极限圆**：标幺值系统中半径为1（电流极限=额定值）
- **电压极限椭圆**：两轴长度与转速成反比，转速增大形成逐渐缩小的一簇套装椭圆
- 定子电流矢量必须同时落在电流极限圆和电压极限椭圆内

### 等转矩曲线

- 恒转矩区运行时，每个转矩值对应多组id/iq组合
- 在id-iq平面形成等转矩曲线（虚线）
- 表贴式(SPMSM)与内嵌式(IPMSM)的等转矩曲线形态不同

## 三种控制策略

### 1. MTPA（最大转矩/电流比）— 恒转矩区

- 同一转速下，使定子电流最小的电流组合 = 等转矩曲线与电流圆的切点
- **表贴式PMSM**：MTPA即Id=0控制
- **内嵌式PMSM**：沿OA线控制Is轨迹
- 运行在电流极限圆内OA1线段上，每点做恒转矩运行

### 2. 弱磁控制 — 恒功率区

- 转速达转折速度ωrt时，电流调节器饱和，丧失对定子电流控制能力
- 控制方式：减小iq，增大反向id（去磁电流分量）
- 反向id产生的磁动势对永磁体去磁，减弱直轴磁场 → 维持高速电压平衡
- 类似他励直流电机调磁控制
- 运行在电流极限圆与电压极限椭圆交点（A1A2段）
- 转速范围得到扩展

### 3. MTPV（最大转矩/电压比）— 高速区

- 转速进一步升高，弱磁恒功率控制功率反而下降
- 放弃弱磁恒功率，在U≤Umax约束下输出尽可能大转矩
- 运行点为电压极限椭圆与等转矩曲线的切点（A2A4段）
- 此时Is＜Imax，U=Umax

## 关键参数

| 参数 | 含义 |
|------|------|
| ωrt | 转折速度，恒转矩区最高转速 |
| A1点 | 最大转矩输出点，电流极限圆上的MTPA终点 |
| A1A2段 | 弱磁恒功率运行区 |
| A2A4段 | MTPV运行区 |
