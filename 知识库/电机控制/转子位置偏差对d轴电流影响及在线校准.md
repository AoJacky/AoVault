# 转子位置偏差对d轴电流影响的分析及汇川在线校准方案

> 编码器安装偏差、温度漂移等导致转子位置误差Δθ，通过Park变换直接影响d/q轴电流观测值，进而影响控制性能。

## 摘要

本文从Park变换的数学推导出发，分析转子位置偏差Δθ对d轴和q轴电流的影响：Δid≈-iq_ref·Δθ（转矩电流耦合效应），Δiq≈-id_ref·Δθ（励磁电流耦合效应）。q轴电流越大，角度误差对d轴观测值影响越大。并介绍了汇川的在线校准方案。

## 原文要点

### 1. 坐标变换

PMSM矢量控制通过Park变换将静止坐标系(α-β)电流转换到旋转坐标系(d-q)：

id_ctrl = iα·cos(θctrl) + iβ·sin(θctrl)
iq_ctrl = -iα·sin(θctrl) + iβ·cos(θctrl)

其中θctrl是控制器使用的角度。

### 2. 角度误差时的变换关系

当存在转子位置误差Δθ时：θctrl = θreal + Δθ

利用三角函数和角公式展开，可以得到控制器观测到的dq电流与真实dq电流的关系：

id_ctrl = id_real·cos(Δθ) + iq_real·sin(Δθ)
iq_ctrl = -id_real·sin(Δθ) + iq_real·cos(Δθ)

### 3. 小角度近似（Δθ很小时）

当Δθ很小（几度以内）时：
- cos(Δθ) ≈ 1
- sin(Δθ) ≈ Δθ

代入得到：

**Δid ≈ -iq_ref · Δθ** （转矩电流耦合效应）
**Δiq ≈ -id_ref · Δθ** （励磁电流耦合效应）

### 4. 影响分析

| 电流分量 | 偏差公式 | 影响 |
|---------|---------|------|
| Id | Δid ≈ -iq_ref·Δθ | q轴电流（转矩分量）越大，相同角度误差对d轴观测值影响越大 |
| Iq | Δiq ≈ -id_ref·Δθ | d轴电流（励磁分量）越大，相同角度误差对q轴观测值影响越大 |

**关键结论**：
- 角度误差导致d/q轴交叉耦合：d轴观测值受q轴电流影响，q轴观测值受d轴电流影响
- 负载越大（iq越大），角度误差对d轴电流的影响越显著
- 这解释了为什么重载时id_ref=0控制策略下，id会出现偏移
