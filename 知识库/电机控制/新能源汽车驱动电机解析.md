# 新能源汽车驱动电机解析

## 驱动电机系统组成

驱动电机系统 = 电机 + 控制器，决定爬坡、加速、最高车速等核心性能指标。

电机组成：定子、转子、机壳、连接器、旋转变压器等

## 电机分类

| 类型 | 应用 |
|------|------|
| 直流（无刷）电机 | 乘用车/商用车 |
| 交流感应（异步）电机 | 欧美车系为主，商用车/客车 |
| **永磁同步电机** | 日韩车系为主，**新能源乘用车主流** |
| 开关磁阻电机 | 商用车（实际装配少） |

其他类型（市场化少）：轮毂电机、混合励磁电机、多相电机、双机械端口能量变换器(Dmp-EVT)

## 动力系统三代演进

| 代次 | 技术 | 特点 |
|------|------|------|
| 第一代 | 中央电机集中驱动 | 传统方案 |
| 第二代 | 轮边电机 | — |
| 第三代 | **轮毂电机** | 纯电动汽车终极解决方案 |

## 轮毂电机优点

1. **高效率**：直接驱动车轮，避免传动损失，效率提升8%~15%，增加续航里程
2. **节省空间**：动力/传动/制动集成到轮毂内，省去变速箱、传动轴
3. **易控制**：电机直接驱动车轮，指令直接控制转速和扭矩，精度高
4. **低成本**：省去复杂传动和制动装置，零部件更少
5. **模块化**：高集成度，只与车轮大小有关，缩短开发周期

## 轮毂电机技术难点

1. **簧下质量增大**：悬架响应变慢，轮毂转动惯量增加使加速响应慢
2. **电制动容量小**：不能满足整车制动要求，需附加机械制动→更大能量消耗→影响续航
3. **工作环境恶劣**：防水防尘防震要求高，冷却散热是技术难点
