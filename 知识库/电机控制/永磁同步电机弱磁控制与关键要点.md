# 永磁同步电机弱磁控制与关键要点

> PMSM弱磁控制原理、四种弱磁方法对比、特征电流意义、ADC采样要点、旋变安装误差影响。

## 摘要

牟特科技梁亚非详解PMSM弱磁控制：D-Q轴坐标系与转矩公式、MTPA电流轨迹、电压椭圆与电流圆约束下三种特征电流情况、四种弱磁方法总结、特征电流/ADC采样/位置延时/旋变安装误差等关键要点。

## 原文要点

### PMSM原理
- 三相ABC坐标→D-Q轴坐标：D轴固定在永磁磁链方向
- 转矩 = 永磁转矩 + 磁阻转矩
- 控制策略：矢量控制+闭环+MTPA+弱磁

### 弱磁控制核心
- 电压椭圆（IPM）vs 电流圆约束，运行区间为两者交集
- 特征电流 I_ch = ψ_f / L_d（短路电流），决定椭圆中心位置

### 三种特征电流情况
1. **I_ch在电流圆外**：弱磁区间有限，高速转矩衰减大
2. **I_ch在电流圆上**：临界状态
3. **I_ch在电流圆内**：理论上可无限弱磁

### 四种弱磁方法总结
1. **电压闭环反馈弱磁法**：基础方法，适合初学者和性能要求不高场合
2. **单张表格转速/电压查表**：性价比好，国内第一梯队有使用
3. **多张表格查表（电感/磁链参数）**：外企背景供应商使用较多
4. **磁链闭环弱磁**：国内第一梯队供应商有使用
- 查表+电压闭环结合使用，动态性能和鲁棒性更好

### ADC采样要点
1. ADC采样与位置采样尽量同步
2. 采样避开PWM切换时间点
3. 采集两相用于FOC，第三相冗余
4. FOC两相尽量双路同步采样
5. 多次采样策略：两次均值/三次去极值/四次去极值取平均

### 旋变安装误差
- 误差θ = θ_fix（固定偏差）+ Δθ（工艺不固定偏差）
- 成因：旋变定子定位、电机定子壳体定位、壳体与端盖定位、转子与转轴定位、下线方式、旋变零位公差
- 影响：功率输出降低（12米纯电公交70km/h@2500rpm场景为例）
