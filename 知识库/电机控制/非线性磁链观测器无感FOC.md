# 基于非线性磁链观测器的无感FOC电机控制及应用

## 为什么选磁链观测器？

| 观测器 | 缺点 |
|--------|------|
| 卡尔曼 | 运算量大，一般定点/浮点跑不起来 |
| 滑模/龙伯格 | 需强制启动，无反电动势时无法启动 |
| 高频注入 | 需凸极性，部分场合不适用 |
| 电流误差估算 | 参数多，不好调 |
| **非线性磁链观测器** | **参数只有γ一个，非常好调** ✅ |

## FOC无感框架

三相电流采集→Clarke→Park→PI控制器→反Park→SVPWM→逆变器开关信号

Park/反Park需要角度→无位置传感器→**位置观测器**观测位置

## 非线性磁链观测器推导

来源论文：《Sensorless Control of Surface-Mount Permanent-Magnet Synchronous Motors Based on a Nonlinear Observer》(2010)

1. SPMSM动态方程和转矩方程
2. 定义状态变量z，z的导数包含转子位置信息
3. 当z估计值与真实值一致→位置确定→反正切得角度
4. 静止坐标系电压方程→磁链方程→引入η向量
5. 构建观测器：**ẑ = f(z) + γ(ẑ - z)/‖ẑ - z‖**（γ>0为增益）
6. 观测到z_α、z_β后，通过反正切获取角度

## 参数调节

- **γ只有一个参数**，非常简单
- 经验：电机电阻~0.1Ω时，γ在30万~50万
- 趋势：电阻越小，磁链越小→γ取越大
- γ是为了抵消参数误差带来的影响

## 实验

- **实验一**：零速/低速启动，6Hz电流频率(72rpm)，额定3000rpm电机→低速性能好
- **实验二**：96MHz下高速风筒，~9.6万转，启动不抖动，初始位置观测准，额定负载启动
  - 10万转：最低载频16kHz，最高40kHz
  - 40kHz下算法6us算完+采样8us

## 芯片CA32M03X

- MCU不含预驱(高压310V/380V) / CA32M031含6N预驱(200V)
- 集成三角函数模块、SVPWM模块，开关频率可达50kHz
