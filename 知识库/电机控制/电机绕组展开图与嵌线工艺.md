# 电机绕组展开图与嵌线工艺

## 第一节 三相单层链式绕组

- 形状/节距相同的线圈连接，外形如长链
- 端部连线短，省铜，用于q=2的4、6、8极小型异步电机
- 例：4极24槽，节距1-6
- **嵌线规律：嵌1空1吊2**
- 同相线圈首首相连、尾尾相连

## 第二节 三相单层同心式绕组

- 几何尺寸/节距不等的线圈连成同心形状
- 端部连线较长，适用于q=4,6,8等偶数的2极小型异步电机
- 例：2极24槽，节距1-10、24-11
- **嵌线规律：嵌2空2吊4**
- 每组同心线圈串联（首尾相连），同相2组首首/尾尾相连

### 同心式 vs 链式

- 同心式：2个或更多线圈同心套在一起
- 链式：所有线圈节距相同

## 第三节 三相单层交叉式绕组

- 两种线圈组（两大一小）交叉布置
- 端部连线较短，省铜，用于q>1且为奇数的小型异步电机
- 例：4极36槽，节距1-9（大）和1-8（小）
- **嵌线规律：嵌2空1，嵌1空2……吊3**
- 大线圈间串联（首尾），大小线圈首首/尾尾相连

## 第四节 三相双层绕组

- 每槽放上下两层有效边，节距可改变→改善电动势/磁动势波形
- 技术性能优于单层，稍大容量电机均采用
- 例：4极24槽，节距1-6
- **嵌线规律：每个线圈连续嵌入，吊把线圈=一个节距**

## 嵌线方法综述

1. 单层：**"嵌几，空几，吊几"**；双层：先嵌一个节距下层边→再嵌一个节距上层边
2. 嵌线前把元件一匝匝理顺，不让交叉
3. 槽内尽量不交叉，少量交叉理至端部
4. 初学时线模稍放大（单层好做）
5. 每嵌一个线圈后整形（木棒向外圆周敲打）
6. 第一个元件边拉进，第二个边划进
