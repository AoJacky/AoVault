# 为什么要测量电机相电流

> FOC 算法需要实时知道各相电流的幅度和相位，而频率已知、幅度和相位未知，因此至少要采两相电流才能完成坐标变换与磁场控制。

## 摘要

FOC（磁场定向控制）的核心是将三相电流通过坐标变换分解为励磁分量（Id）和转矩分量（Iq），从而实现对磁场和转矩的独立控制。这一过程的前提是必须知道三相电流的实时值。在三相平衡系统中，三相电流之和为零（$i_a + i_b + i_c = 0$），因此理论上只需测量两相电流即可推算第三相。电流的频率由转子转速决定（已知），但幅度和相位随负载和工况实时变化（未知），必须通过采样获取。

## 原文要点

### 1. 为什么需要三相电流

FOC 算法需要利用三相电流来形成旋转磁场的控制基础：

- Clark 变换需要 $i_a$、$i_b$（或 $i_a$、$i_b$、$i_c$）将三相静止坐标系转换为两相静止坐标系（αβ）
- Park 变换再将 αβ 坐标系转换为旋转坐标系（dq）
- 在 dq 坐标系下，Id 控制磁场强度，Iq 控制转矩输出
- 没有准确的电流信息，整个 FOC 控制链路无法闭合

### 2. 电流信号的已知与未知

| 信息 | 状态 | 说明 |
|------|------|------|
| 频率 | 已知 | 由电机转速和极对数决定（$f_e = \frac{n \cdot p}{60}$） |
| 幅度 | 未知 | 随负载变化实时改变 |
| 相位 | 未知 | 与转子位置相关，需要实时跟踪 |

### 3. 为什么至少采两相

三相平衡系统中，三相电流满足约束：

$$i_a + i_b + i_c = 0$$

因此只要知道其中两相，第三相自动确定：

- $i_c = -i_a - i_b$

工程上通常采样 $i_a$ 和 $i_b$，通过软件计算得到 $i_c$，这样可以减少一个电流传感器，降低成本和电路复杂度。

### 4. 常见采样方式

- **相电流采样**：在逆变器下桥臂串联采样电阻（或霍尔传感器），直接测量各相电流
- **母线电流采样**：只在直流母线上采样，通过 PWM 状态推算各相电流（成本最低，但采样窗口受限）
- **两相采样 + 重构**：最常用的折中方案，兼顾成本与精度

## 个人想法

电流采样是 FOC 的"眼睛"，采样精度和实时性直接影响控制性能。采样电阻的选择、ADC 采样时刻的对齐（与 PWM 同步）、以及采样噪声的滤波，都是工程实现中需要关注的细节。
