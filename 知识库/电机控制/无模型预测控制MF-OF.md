# 无模型预测控制（无观测器）——MF-OF用三行公式终结参数焦虑

> MF-ESO走"增强感知"路线，MF-OF走"直接求解"路线。MF-OF仅凭几组电流电压数据，用消元法直接算出控制指令，无需观测器、无需参数辨识。

## 摘要

本文对比了两种无模型控制方法的哲学差异：MF-ESO（模型无关扩展状态观测器）通过设计观测器估计扰动，MF-OF（无模型无观测器）通过超局部模型+消元法直接求解。MF-OF的核心是三行公式：相邻时刻方程相减消去扰动项，直接计算系统参数α和扰动F，仅需基础四则运算。

## 原文要点

### 01 MF-ESO：精密而复杂的"感知-决策"闭环

MF-ESO为控制系统安装"软件观测器"，实时估算未知扰动和状态。

**d轴观测器**：一组联立微分方程，通过增益β₁和β₂让虚拟模型跟踪真实系统。

**带宽参数化**：设定观测器带宽ωb，令β₁=2ωb，β₂=ωb²，将复杂设计转化为单参数选择。

**代价**：
- 高带宽→噪声敏感
- 低带宽→响应滞后
- 增益整定与噪声抑制的矛盾

流程：复杂观测器设计 → 实时状态估计 → 精密补偿

### 02 MF-OF：大道至简的"数据-行动"直连

**超局部模型**：

```
di/dt = α·u + F
```

- α：系统输入增益（实时计算，不依赖先验参数）
- F： lumped disturbance（包含所有未建模动态、参数不确定性、外部扰动）
- 不试图拆解F，而是实时计算此刻有效的α和F

**消元法——MF-OF的灵魂**：

假设微小控制周期内系统特性不变，写出相邻k和k-1时刻的方程：

```
di(k)/dt = α·u(k) + F
di(k-1)/dt = α·u(k-1) + F
```

两式相减，**F被完美消去**：

```
α = [di(k)/dt - di(k-1)/dt] / [u(k) - u(k-1)]
```

**无需迭代、无需优化，三次电流采样+两次电压记录即可直接算出α。**

算出α后，F唾手可得：

```
F = di(k)/dt - α·u(k)
```

### 03 MF-ESO vs MF-OF 对比

| 特性 | MF-ESO（复杂感知派） | MF-OF（直接求解派） |
|------|---------------------|---------------------|
| 核心哲学 | 增强感知，洞察一切后再决策 | 基于最直接的数据关系，求解当前最优动作 |
| 数学工具 | 状态空间、观测器理论、频域分析 | 代数方程、差分计算、消元法 |
| 复杂度 | 高（需设计观测器结构与参数） | 极低（固定公式，直接套用） |
| 计算负担 | 中高（需迭代更新观测器状态） | 极低（基础四则运算） |
| 可解释性 | 复杂，需专业知识理解内部状态 | 极高，每一步都有明确代数意义 |
| 调试维护 | 困难，多参数耦合，牵一发动全身 | 简单，参数少，行为可预测 |

### 04 MF-OF"简单"为何有力

- 无需先验模型参数
- 无需观测器设计和整定
- 计算量极小，适合资源受限MCU
- 代数推导透明，每步可解释
