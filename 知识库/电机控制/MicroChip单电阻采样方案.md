# Microchip 单电阻采样方案

> 在直流母线上仅用一个采样电阻即可重构三相电流，核心思路是一个 PWM 周期内采样两次母线电流（分别对应不同下桥臂导通时刻），再通过软件算法还原三相电流值。

## 摘要

Microchip 的单电阻采样方案用一个电流检测电路替代传统两相/三相采样，显著降低硬件成本并简化功率模块设计。其原理是在每个 PWM 周期内，利用两个不同下桥臂导通的时刻分别采样母线电流，从而获取两相电流信息，再结合三相平衡约束重构出完整的三相电流。该方案的代价是需要修改 PWM 调制策略以保证足够的采样窗口，同时增加了 CPU 的计算开销。

## 原文要点

### 1. 方案优点

- **降低硬件成本**：只需一个采样电阻和一套放大/滤波电路，相比两相采样省去一套传感器
- **高效使用功率模块**：不需要为每相桥臂单独引出功率管的发射极（sense 引脚），功率模块选型更灵活
- **三相一致性好**：三相电流经过同一检测电路，增益和偏移完全相同，无需逐相校准放大电路或在软件中做补偿

### 2. 方案缺点

- **存在采样窗口限制**：硬件上只有在特定下桥臂导通时才能采样到有效母线电流，采样窗口受 PWM 占空比约束
- **需要修改 PWM 调制**：为了保证足够的采样窗口，必须对标准正弦调制（SPWM/SVPWM）进行调整，可能引入额外的电流纹波
- **CPU 资源占用增加**：一个 PWM 周期内要完成两次 ADC 采样、两次电流重构计算，对控制器算力要求更高

核心思路：在 SVPWM 的两个有效矢量作用期间，母线电流分别等于某一相的相电流。通过在两个有效矢量对应的时刻采样，可以得到两相电流，再利用 $i_a + i_b + i_c = 0$ 重构第三相。

### 4. 关键约束

- **最小脉宽要求**：两个有效矢量的作用时间必须大于 ADC 采样建立时间 + 转换时间，否则采样窗口不足
- **低占空比/高占空比区域**：当某一相占空比接近 0% 或 100% 时，对应有效矢量时间过短，可能无法采样，需要通过 PWM 移相或注入脉冲来保证采样窗口
- **采样时刻对齐**：ADC 触发必须与 PWM 中心对齐，避免在开关瞬态采样引入噪声

## 个人想法

单电阻方案的核心挑战在于 PWM 调制的修改和采样窗口的保证。在高调制比或极低速时，有效矢量时间可能不够采样，此时需要额外的 PWM 修正策略（如移相法或脉冲注入法），这会增加谐波和转矩脉动。实际选型时需要权衡成本节省与控制性能的取舍。
