# 电机控制——单电阻电流采样

> 单电阻分时采样重构三相电流：成本最低，但需要处理采样窗口不足和震荡问题。

## 分流电阻采样方案对比

| 方案 | 电阻数 | 特点 |
|------|--------|------|
| 三电阻 | 3 | 同时采样，精度最高，成本高 |
| 两电阻 | 2 | 平衡成本和精度 |
| **单电阻** | 1 | 成本最低，需分时采样+重构 |

单电阻：在下桥臂母线处放置一个采样电阻，分时采集一个周期内两次电流，重构三相电流。

## 采样原理

7段式SVPWM一个载波周期：
**零矢量T0 → 死区DT → 有效矢量T1 → 死区DT → 有效矢量T2 → ...**

采样时刻在T1和T2即可获得正确信号。

## 采样窗口问题

### 震荡问题
采样电阻上波形震荡和毛刺明显：
- **第一个震荡**：发生在上桥MOS打开时，或下桥关闭时（DT开始和结束）
- **大窗口**（DT+T1宽）：震荡结束后有平稳信号供采样 ✓
- **小窗口**（DT+T2窄）：整个窗口都是震荡，采样失真 ✗ → 启动容易失败

### 最小采样窗口
扇区边界处驱动波形出现**"两长一短"或"两短一长"**，导致一个有效采样区间很小甚至没有。

**解决方案**：最小采样窗口补偿
1. 窗口不足时：前半周期删减，后半周期补偿
2. 电流采样在前半周期完成，后半周期窗口无关
3. 同一电周期补偿，三相占空比不变，不影响合成矢量

## 硬件优化建议

1. 采样电阻信号线**差分走线**，推荐**开尔文接法**
2. 驱动地和采样电阻地**分开走线**
3. 地线回路尽可能短，电容靠近芯片
4. C33不宜太大，R34上不并电容，VCC和I_Shunt间不加电容
5. RC滤波（R51+C39）取平均电流做功率闭环：
   - RC太大会导致电流滞后、功率环震荡
   - R51太大会导致ADC采样值偏小
