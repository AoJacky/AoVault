# 看完此文，菜鸟都会选择MOSFET！

> 一文读懂MOSFET数据表解读、关键指标选取和四步选型法，从电压等级、导通电阻、额定电流到开关性能全面掌握。

## 摘要

本文系统讲解了MOSFET数据表解读方法和选型四步法。核心观点：数据表每一页都有价值，关键是要理解测试条件、区分最大/典型值、掌握温度系数影响。通过四个步骤——选沟道类型→确定额定电流→计算热要求→决定开关性能——可完成MOSFET的完整选型。

## 原文要点

### 一、数据表解读基础

**重要原则**：
- 数据表每一页都有价值，不只是第二页以后
- 必须了解**测试条件**——指标在什么条件下应用
- 分清**最大**和**典型**值——有些数据表不说明清楚

### 二、电压等级（VDS）

**定义**：栅极短路到源极，漏极电流250μA时的最高不损坏电压

**关键要点**：
- VDS与温度有关，数据表有"VDS温度系数"
- 最高VDS = 直流电压 + 电压尖峰 + 纹波
- **案例**：30V电源+100mV/5ns尖峰 → 超过30V器件极限 → 可能进入雪崩模式
- 高温下温度系数会显著改变击穿电压
- 600V N沟道MOSFET在高温下温度系数为正 → 实际像650V器件
- **设计规则**：需要10%～20%降额因子
- 考虑实际击穿电压比额定高5%~10%，增加设计裕量

**VGS（栅源电压）的作用**：
- 确保MOSFET完全导通的最低电压
- 导通电阻总是与VGS水平关联
- **不能**用低于RDS(on)额定值对应的VGS来完全导通
- 例：3.3V微控制器驱动 → 选用VGS=2.5V或更低即可导通的MOSFET

### 三、导通电阻、栅极电荷与优值系数

**RDS(on)**：
- 通常在25℃结温下给出
- 最大限值可比典型值高20%～50%
- 高温下RDS(on)可增加30%～150%
- 不建议用RDS(on)检测电流（因温度非线性）

**Qg（栅极电荷）**：
- N沟道MOSFET的关键选择标准
- 影响开关损耗：①转换时间 ②每次开关对栅极电容充电能量
- Qg取决于VGS——降低VGS可减少开关损耗

**优值系数（FOM）**：
```
FOM = RDS(on) × Qg
```
- 快速比较开关应用中MOSFET性能的单数公式
- 传导损耗用RDS(on)表示，开关损耗用Qg表示
- **必须确保RDS(on)和Qg使用相同的VGS进行比较**
- 典型值和最大值不能混用
- 较低的FOM获得更好性能，但需实际电路验证

### 四、额定电流和功率耗散

**电流额定值**：
- 仔细查看测试条件：外壳温度（TC=25℃）还是环境温度（TA=25℃）
- 手持设备小型SMD器件 → 70℃环境温度下的电流最相关
- 有散热片和强制风冷的大型设备 → TA=25℃更接近实际
- "管芯限定"电流 vs "封装限定"电流——管芯可能比封装能处理更大电流

**功率耗散**：
- 不仅取决于温度，还取决于导通时间
- 使用**热瞬态阻抗图**判断不同脉冲宽度下的功率耗散
- 例：PD=4W连续工作10秒 → 10秒脉冲后热阻系数≈0.33
  - 10分钟后热饱和 → 散热能力仅1.33W（而非4W）
  - 良好冷却下可达2W左右

**雪崩击穿**：
- 反向电压超最大值 → 强电场 → 电流增加 → 温度升高 → 可能损坏器件
- 两种计算方法：统计法、热计算（热计算更实用）
- 晶片尺寸增加 → 抗雪崩能力提高
- 需足够余量覆盖整个工作温度范围

### 五、MOSFET选型四步法

#### 第一步：N沟道还是P沟道

| 应用类型 | 推荐沟道 | 原因 |
|----------|----------|------|
| 低压侧开关（MOSFET接地，负载接总线） | **N沟道** | 关闭/导通所需电压容易实现 |
| 高压侧开关（MOSFET接总线，负载接地） | **P沟道** | 电压驱动更简单 |

**额定电压选择**：
- 必须大于干线/总线电压（提供保护裕量）
- 考虑温度变化范围
- 考虑开关电子设备诱发的电压瞬变（电机、变压器）
- 典型应用：
  - 便携式设备：20V
  - FPGA电源：20～30V
  - 85～220VAC应用：450～600V

#### 第二步：确定额定电流

**两种电流情况**：
1. **连续模式**：稳态，电流连续通过器件
2. **脉冲尖峰**：大量电涌流过器件

**导通损耗计算**：
```
Ploss = Iload² × RDS(on)
```
- RDS(on)随温度显著变化
- VGS越高 → RDS(on)越小 → 折中权衡
- 便携式设计：较低电压较容易
- 工业设计：可采用较高电压

**RDS(on)随电流轻微上升**——查看制造商技术资料

**先进技术对比**：
- 标准技术：VDS↑ → RDS(on)指数级↑ → 晶片尺寸↑
- **沟道技术**：深沟嵌入降低RDS(on)，外延生长柱/蚀刻柱工艺
- **SuperFET技术**（飞兆半导体）：
  - 将RDS(on)与晶片尺寸的指数关系变为线性关系
  - 晶片尺寸可减小达35%
  - 封装尺寸大幅减小

#### 第三步：确定热要求

**最坏情况 vs 真实情况**——建议采用最坏情况计算结果（更大安全余量）

**结温计算**：
```
结温 = 最大环境温度 + (热阻 × 功率耗散)
      = Ta_max + (θJA × I²×RDS(on))
```

**热容量考虑**：
- 结/外壳热容量
- 外壳/环境热容量
- PCB和封装不会立即升温

#### 第四步：决定开关性能

**影响开关性能的参数**：
- 栅极/漏极电容（Cgd）
- 栅极/源极电容（Cgs）
- 漏极/源极电容（Cds）

**开关损耗计算**：
```
Psw = (Eon + Eoff) × 开关频率
```

**栅极电荷Qgd对开关性能影响最大**

**新技术应对开关问题**：
- 芯片尺寸增加 → 栅极电荷增加 → 器件尺寸增大
- **沟道厚底氧化技术**：减少栅极电荷
- SuperFET：降低RDS(on)和Qg → 传导损耗↓ + 开关性能↑
- 可应对高速电压瞬变(dv/dt)和电流瞬变(di/dt)
- 可在更高开关频率下可靠工作

### 六、总结

| 选型步骤 | 关键考量 |
|----------|----------|
| 1. 选沟道类型 | 低压侧→N沟道；高压侧→P沟道 |
| 2. 定额定电流 | 连续+脉冲尖峰；计算导通损耗；选先进技术降RDS(on) |
| 3. 算热要求 | 最坏情况结温；热瞬态阻抗；雪崩额定值 |
| 4. 定开关性能 | Cgd/Cgs/Cds电容；Qgd栅极电荷；Eon/Eoff损耗 |
