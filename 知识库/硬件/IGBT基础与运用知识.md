# IGBT基础与运用知识

> IGBT = MOSFET(输入级) + PNP晶体管(输出级)，兼具MOSFET驱动功率小、开关速度快和双极型器件饱和压降低、容量大的特点，频率范围几十kHz。

## 等效电路

理想等效电路与实际等效电路（MOSFET+PNP复合）。重点考虑动态特性（开关特性）。

## 开通过程（5阶段）

| 阶段 | 过程 |
|------|------|
| **第1阶段** | 栅极电流对C_GE充电，V_GE上升到开启阈值V_GE(th)，集电极无电流，即死区时间 |
| **第2阶段** | 栅极电流对C_GE+C_GC充电，集电极电流开始增加至最大负载电流I_C，V_GE到达米勒平台电压 |
| **第3阶段** | V_GE不变（米勒平台），V_CE变化非常快 |
| **第4阶段** | V_CE缓慢变化到稳态，米勒电容随电压减小而增大，V_GE仍在米勒平台 |
| **第5阶段** | 栅极电流继续对C_GE充电，V_GE开始上升，IGBT完全导通 |

## 关断过程

漏极电流分两段：
1. **第一段**：按MOS管关断特性
2. **第二段**：MOSFET关断后，PNP晶体管存储电荷难释放，产生较长**尾部电流**

关断时间：t_off = t_d(off) + t_rv + t_f

## 关键电容参数

| 参数 | 公式 |
|------|------|
| 输入电容 | C_ies = C_GE + C_GC |
| 反向电容 | C_res = C_GC |
| 输出电容 | C_oes = C_GC + C_CE |

## 栅极驱动设计

### 栅极电阻
- **阻值小**：充放电快，减小开关时间和损耗，防dv/dt误导通；但电压尖峰大，易寄生振荡
- **阻值大**：充放电慢，开关时间和损耗增大

### 栅极电压
- 开通电压：**15V±10%**（完全饱和，开关损耗最小）；<12V通态损耗加大，>20V难以过流保护
- 关断偏压：**-5~-15V**（防噪声误导通，减小关断损耗），最佳约**-8~-10V**

### 栅极参数影响
- IGBT续流二极管开关特性也受栅极电阻影响
- 栅极电阻减小→IGBT过电压应力↑ + 续流二极管过压↑

### PCB布线要点
- 核心问题：**降低寄生电感**
- 驱动至栅极引线加粗
- 控制板与功率电路防止电感耦合
- 不能直接连接时用双股绞线(<3cm)或同轴线

### 栅极保护
- 用TVS等箝位保护，放置在IGBT模块栅极和发射极控制端子附近

### 耦合干扰与噪声
- PCB连线不宜太近，高dv/dt通过寄生电容产生耦合噪声
- 减少器件间寄生电容

## 死区时间

- 上下桥臂同时关断时间，保证驱动安全
- 死区大→可靠性↑ 但波形失真、效率↓
- 死区小→波形好 但可靠性↓
- 典型值：**≥3μs**
- 环境温度对t_off影响大，需调整
