# 功率MOSFET详解——等效电路与开关过程

> 功率MOSFET各工作状态等效电路、稳态特性、开通关断过程、功率损耗公式及选型原则。

## 摘要

详解功率MOSFET的正向导通/反向导通/正向截止等效电路、含寄生参数的等效模型、开通关断过程时序分析、Miller电容效应、二极管反向恢复对开关波形影响、功率损耗公式（导通/开关/驱动损耗）及选型原则步骤。

## 原文要点

### 正向导通等效电路
- 可用电阻等效，与温度正比（温度↑→电阻↑），与Vgs反比（Vgs↑→电阻↓）

### 反向导通（门极不加控制）
- 体二极管等效，特性差，应避免使用

### 反向导通（门极加控制）——同步整流
- 也可用电阻等效，与温度正比，与Vgs反比
- 低压大电流输出开关电源中极重要的工作状态
- 目前最小通态电阻2-4mΩ

### 正向截止等效电路
- 可用电容等效，容量与正向电压、温度有关

### 稳态特性总结
- Vgs<Vth(≈3V)断开，Vgs>Vth导通；额定Vgs为12-15V
- 通态电阻正温度系数，原理上易并联扩容（实际需考虑驱动对称性和动态均流）
- Logic-Level MOSFET：Vgs仅需5V

### 含寄生参数的等效电路
- 3个结电容 + 3个沟道电阻 + 体二极管 + 理想MOSFET
- 结电容均与结电压有关

### 开通过程 [t0~t4]
1. t0→t1：Vgg对Cgs充电至Vth，开始导电
2. t1→t2：DS电流增加，Miller电容放电
3. t2→t3：DS电压降至与Vgs相同，Miller电容大增，GS电压不变（Miller平台）
4. t3→t4：Miller电容变小，与Cgs一起充电至稳态

### 关断过程 [t5~t9]
- 反向对称过程，Miller平台同样出现

### 功率损耗公式
- **导通损耗**：Pcond = I²·Rds(on)·D（同步整流适用）；体二极管导通时P = Vf·If·(1-D)
- **容性开通+感性关断损耗**
- **开关损耗**：开通+关断（考虑二极管反向恢复）
- **驱动损耗**：Pdrive = Qg·Vgs·fsw

### 选型原则
- 工作电流大时：选Rds(on)小 + 结电容小的器件
- 选型步骤：计算稳态参数→从Datasheet初选→估算损耗→实验确定

### 电子开关分类
- 按材料：Si、GaAs、SiC、GaN（下一代）、Diamond（再下一代）
- 按可控性：不控(二极管)、半控(SCR)、全控(MOSFET/IGBT/GTO)
- 按频率：低频(SCR)、中频(IGBT/GTR)、高频(MOSFET/SBD)
- 按功率：小(MOSFET)、中(IGBT)、大(GTO)
- 按载流子：多子器件(MOSFET/SBD)、少子器件(IGBT/GTR)
