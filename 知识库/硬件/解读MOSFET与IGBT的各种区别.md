# 解读MOSFET与IGBT的各种区别

> MOSFET和IGBT没有本质好坏，只有适用场景不同。MOSFET高频低压，IGBT高压低频，选型需权衡导通损耗、开关损耗、工作频率、成本等因素。

## 摘要

本文系统对比了MOSFET与IGBT的结构差异、应用特点、三大损耗（导通损耗、传导损耗、关断损耗）特性，以及栅极驱动设计要点。核心结论：两者无绝对好坏，适用场景不同——MOSFET适合高频（数百kHz~MHz）、低压应用；IGBT适合高压大功率、中低频率应用。

## 原文要点

### 一、结构与基本区别

| 特性 | MOSFET | IGBT |
|------|--------|------|
| 内部结构 | 纯MOS结构 | MOS+PNP BJT复合结构 |
| 耐压能力 | 较弱 | **强** |
| 电流能力 | 可达kA级 | 可做大功率 |
| 工作频率 | **数百kHz~MHz** | 最高~100kHz（硬开关） |
| 典型应用 | 开关电源、镇流器、高频感应加热、通信电源 | 焊机、变频器、电镀电解电源、超音频感应加热 |

**核心结论**：MOSFET高频性能好，IGBT耐压/功率能力强，两者适用场景不同。

### 二、导通损耗

**相同点**：除了IGBT有较长的电压下降时间外，两者导通特性类似。

**IGBT特有现象**：
- **电压拖尾（Voltage Tail）**：完全调节PNP BJT集电极基极区的少数载流子所需时间导致
- **类饱和效应**：使VCE不能立即下降到VCE(sat)值
- **Eon分为两部分**：Eon1（无硬开关二极管恢复损耗）+ Eon2（含二极管恢复损耗）

**硬开关导通关键点**：
- 栅极驱动电压/阻抗 + 整流二极管恢复特性决定Eon损耗
- 对CCM升压PFC电路，升压二极管恢复特性极为重要
- 选择最小Trr和QRR的升压二极管，并确保**软恢复特性**
- 软化度（Softness）= tb/ta比率，影响EMI和电压尖峰

**栅极驱动阻抗设计**：
- 降低驱动源阻抗 → 提高di/dt → 减小Eon损耗
- 但di/dt过高 → 电压尖峰、EMI增加 → 需折中
- 公式：Z = (Vdrive - VGS(avg)) / (GFS(avg) × Vdrive / di/dt)
- MOSFET例：Vdrive=10V, di/dt=600A/μs → Z≈37Ω
- IGBT例：计算得Z≈100Ω（IGBT GFS较高，CIES较低）
- **从MOSFET转IGBT需重新设计栅极驱动电路**

### 三、传导损耗

**600V器件对比（同芯片大小，125°C结温）**：
- IGBT传导损耗一般比MOSFET小
- FGP20N6S2 IGBT vs FCP11N60 SuperFET MOSFET（均RθJC=1℃/W）
- 直流比较：2.92A后MOSFET损耗更大
- PFC电路实际运行（85V AC输入，400V DC输出）：2.65A RMS时相交
  - >2.65A RMS：MOSFET传导损耗更大
  - IGBT可传导**超过MOSFET 70%的功率**

**RDS(on)非线性特性**：
- RDS(on)随漏极电流变化（非线性）
- 大部分SMPS拓扑影响小（<5%）
- 高脉冲电流、小占空比应用需考虑
- 例：20A脉冲（7.5%占空比），RDS(on)增大25%

**并联特性**：
- IGBT（PT型）：**NTC负温度系数**，不能并联分流
- MOSFET：**PTC正温度系数**，可良好电流分流

### 四、关断损耗

**硬开关关断**：
- **MOSFET关断损耗远低于IGBT**
- 原因：IGBT有拖尾电流（少数载流子清除延迟）
- Eoff测试条件（VDD钳位电压）需注意，不同厂商不同

**栅极驱动影响**：
- 降低关断阻抗对减小Eoff影响极微
- 但可降低米勒电容CRES引起的误触发风险
- 避免多个开关动作产生额外Eoff

**软开关优势**：
- **ZVS**：对MOSFET优势明显，对IGBT优势小（拖尾冲击电流）
- **ZCS**：可显著提升IGBT Eoff性能
  - 关键：栅极信号在第二个集电极电流过零点前不被清除

**MOSFET关断损耗影响因素**：
- 米勒电容Crss
- 栅极驱动速度
- 栅极驱动关断源阻抗
- 源极功率电路路径寄生电感Lx
- 例：Lx=5nH, VGS(th)=4V → 最大di/dt=800A/μs

### 五、选型总结

| 场景 | 推荐器件 | 原因 |
|------|----------|------|
| ZVS/ZCS高频应用 | **MOSFET** | 开关速度快，关断损耗低 |
| 硬开关高频应用 | **MOSFET**（注意体二极管） | 体二极管恢复特性是限制因素 |
| 硬开关中低频大功率 | **IGBT** | 传导损耗低，耐压高 |
| 需要并联使用 | **MOSFET** | PTC正温度系数，自动均流 |
| 不能并联场合 | **IGBT** | NTC，需匹配VCE(sat)、VGE(th) |

**最终结论**：
- MOSFET与IGBT没有本质的好坏之分
- 选型需综合考虑：电路拓扑、工作频率、环境温度、物理尺寸、成本
- 用辩证的方法考虑，而非简单地"哪个好"
