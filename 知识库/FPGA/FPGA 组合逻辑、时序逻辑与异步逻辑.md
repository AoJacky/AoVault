# FPGA 组合逻辑、时序逻辑与异步逻辑

> 计算用组合逻辑，记忆用时序逻辑，跨界（异步）信号必须先同步才能进入同步系统。

## 摘要

FPGA 中的组合逻辑、时序逻辑与异步逻辑分别对应"纯计算""带记忆的状态"和"不跟随本地时钟的信号/结构"三件事，理解它们的协作关系是数字设计的基础。组合逻辑用 LUT 实现，输出只依赖当前输入、无记忆，会产生传播延迟和毛刺；时序逻辑以 D 触发器为核心，在时钟边沿统一更新，是稳定设计的基础；异步逻辑在工程中通常并非指"无时钟电路"，而是指异步复位、跨时钟域（CDC）信号等需要用特定手段安全接入同步系统的对象。三者配合构成"状态机 + 数据通路"的经典结构，最高时钟频率由 `FF输出 → 组合逻辑 → FF输入` 的关键路径决定。实际选型原则是"能同步就同步"，复位可异步但释放要同步，跨时钟域用两级同步器 / 格雷码 / 握手 / 异步 FIFO。

## 原文要点

### 1. 三者的本质区别

| 类型 | 输出取决于 | 有无记忆 | FPGA 里的实现 | 核心代价 |
|---|---|---|---|---|
| 组合逻辑 | 当前输入 | 无 | LUT + 布线 | 传播延迟、毛刺 |
| 时序逻辑 | 时钟边沿 + 输入 + 状态 | 有 | D 触发器（FF） | 建立/保持时间、时钟偏斜 |
| 异步逻辑 | 与时钟无关，随时变化 | 视情况 | 门电路 / FF 异步端口 / 跨时钟信号 | 亚稳态、时序不可分析 |

一句话记忆：

- **组合逻辑 = 函数**：给输入立即算输出；
- **时序逻辑 = 函数 + 记忆**：在时钟边沿把结果存下来；
- **异步逻辑 = 不跟本时钟走的信号或结构**：需特殊处理才能安全进入同步系统。

### 2. 各自在 FPGA 里的实现

- **组合逻辑**：综合成查找表（LUT），如加法器、多路选择器、译码器、比较器。没有时钟，输入一变输出就变（经门延迟），中间可能产生**毛刺（glitch）**。
- **时序逻辑**：核心是 D 触发器，所有输出在**同一时钟边沿**统一更新，可将组合逻辑的毛刺在边沿处滤掉。
- **异步逻辑**：FPGA 里 90% 的情况不是"设计异步电路"，而是**处理异步信号**——异步复位信号、来自另一时钟域的信号、外部按键/外部芯片信号。真正的"无时钟异步状态机"几乎不用（无法约束、无法做时序分析、易出竞态）。

### 3. 它们如何配合

经典结构是 **状态机 + 数据通路**：

```text
        ┌──────────────┐
 输入 ──▶│  组合逻辑     │──▶ 下一状态 ──┐
        │ next = f(   │              ▼
        │   state, in)│           ┌─────┐
        └──────────────┘    clk ──▶│ FF  │──▶ 当前状态
                                    └─────┘
```

- 组合逻辑负责"算下一拍该是什么"；
- 触发器负责"在时钟边沿把它定下来"；
- 一个时钟周期内的链路为 `FF输出 → 组合逻辑传播 → FF输入建立`，因此最高频率受限于：

$$T_{clk} \ge T_{clk\text{-}to\text{-}Q} + T_{组合延迟} + T_{setup} + 余量$$

这就是"关键路径"的含义。

**异步逻辑如何接入配合：**

1. **异步复位**：直接接 FF 的异步清零端 `always @(posedge clk or negedge rst_n)`，让系统上电无需时钟即可复位，但**释放必须同步**。
2. **跨时钟域（CDC）**：异步信号不能直接喂给本时钟域逻辑，否则亚稳态会传播，必须先同步。

```verilog
// 单比特：两级同步器
reg s1, s2;
always @(posedge clk) begin
    s1 <= async_sig;
    s2 <= s1;      // s2 才是本时钟域可用的信号
end
```

### 4. 实际应用如何正确选择

**默认原则：能同步就同步。** 全同步设计才能做静态时序分析（STA），保证稳定可复现。

**（1）什么时候用组合逻辑**

- 纯运算/选择/译码：加法、MUX、编码、比较、CRC 计算的一部分。
- 注意：`always @(*)` 里所有分支都要赋值（否则综合出 latch）；输出若要上引脚或跨模块，**最好再打一拍**再送出。

**（2）什么时候用（同步）时序逻辑**

- 几乎一切"需要记住的东西"：计数器、状态机、流水线寄存器、数据缓存。
- 模块**输入和输出都寄存一拍**，是提升时序、隔离边界最实用的手段。

**（3）什么时候用异步逻辑（三种正确用法）**

- **异步复位 + 同步释放**（reset synchronizer），兼顾"无时钟也能复位"和"释放不产生亚稳态"：

```verilog
reg rst_sync_n;
reg [1:0] rst_sync;
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) rst_sync <= 2'b00;
    else        rst_sync <= {rst_sync[0], 1'b1};
end
assign rst_sync_n = rst_sync[1];   // 用它去做各模块的复位
```

- **单比特 CDC**：两级 FF 同步器（如上）。
- **多比特 CDC**：用格雷码（计数器）、握手信号、或异步 FIFO，**绝不能**对每根 bit 都各放一个同步器。

### 5. 常见坑

- ❌ 用组合逻辑输出当作时钟（门控时钟）→ 改用 `clock enable`（`if (en) q <= d;`）。
- ❌ `always @(*)` 里 `if` 没写全 → 综合出锁存器 latch（电平敏感、难约束）。
- ❌ 组合逻辑成环（`a = b; b = a;`）→ 无法定时、会振荡。
- ❌ 异步信号不经过同步器就进逻辑 → 亚稳态随机出错。
- ❌ 复位既用异步又同步地混在一个表达式里，或忘了给复位加时序例外（如 `set_false_path` / `set_async_reg`）。
- ✅ 一定写时序约束（XDC/SDC），让工具报出 **setup/hold slack**，不要靠仿真"看起来对"。

### 6. 选型口诀

> 计算用组合，记忆用时序，跨界必须同步；
> 复位可异步、释放要同步；一切握手靠时钟边沿，绝不靠电平。
