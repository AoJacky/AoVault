### 💡方案说明

**问题：** 两个人改了不同参数，PR 还是报 xlsx 冲突，每次都要手动对比。

**改法：** Git 里只存 CSV（文本），xlsx 本地自动生成、不入库（加入.gitignore 列表）。不同人改不同参数 → 自动合并，不再冲突。PR 里还能直接看 diff。

**对开发人员来说：操作完全不变。** 打开 Excel → 修改 → 保存 →编译 → commit，和以前一模一样。转换全是 hook 自动干的，不用管。

**关于 hook：**

- 公共 hook 统一放在仓库 `publichooks/` 目录，入库管理，pull 下来自动生效，不用手动装
- 如果你自己在 `.git/hooks/` 里放过个人脚本，不受影响，两边都会执行。
