
### 简要总结
```
本系列伺服驱动器采用统一接口架构，兼容SmartAbs绝对值编码器（多摩川协议）、EnDat 3高速串行编码器及机械齿轮编码器三类位置反馈方案，覆盖从高精度半导体装备到恶劣环境长周期运行的多元应用需求。软件层通过协议抽象适配所有编码器类型，同一硬件平台即可灵活切换，显著减少产品SKU与备件种类。其中，机械齿轮编码器的零电池多圈记忆机制则彻底消除断电位置丢失风险，为无人值守场景提供最高可靠性保障。
```


### 详细介绍
```
1. SmartAbs 绝对值编码器

采用多摩川（Tamagawa）串行通信协议实现多圈绝对值位置反馈。多摩川协议是工业界广泛应用的编码器串行协议之一，兼容性好、生态成熟。上电后驱动器自动完成编码器类型识别与参数配置，无需手动设定或回零操作。单圈23 bit分辨率配合串行差分传输，在长电缆（≤100 m）工业布线场景下具备优异抗干扰能力。断电后依靠内部电池保持多圈位置信息，适用于需要快速启动、免回零的通用自动化设备。

2. EnDat 3 编码器

基于HEIDENHAIN EnDat 3协议，是本系列驱动器支持的最高性能编码器接口。协议传输速率可达12.5/25 MHz，位置数据刷新周期进入微秒量级，有效缩短反馈延迟对位置环带宽的制约，使伺服系统在高动态工况下仍保持稳定跟踪精度。单圈分辨率32 bit，满足半导体光刻、精密数控等纳米级定位需求。
EnDat 3独有安全数据通道功能，编码器可同时提供标准位置数据与经CRC校验的安全位置/安全速度数据，驱动器内建安全逻辑据此直接执行SS1/SS2（安全停机）、SLS（安全限速）等功能，免除独立安全编码器与双通道布线，简化系统架构并降低认证成本。
此外，EnDat 3支持编码器端在线诊断信息回传（内部温度、信号幅值、错误计数器等），驱动器据此实现编码器健康状态监控与预测性维护预警。

3. 机械齿轮编码器

通过内置精密齿轮减速机构将电机主轴旋转传递至多圈计数轮系，实现纯机械式多圈绝对位置记忆。齿轮级通常为4~~5级，对应4,096~~65,536圈的多圈记录范围。断电后位置信息由齿轮物理位置保持，不依赖电池或韦根传感器，不存在电量耗尽导致位置丢失的隐患，断电保持时间无上限。该方案特别适用于高温环境（电池加速老化）、强振动工况（WDT信号不稳定）以及长周期无人值守运行（如远程泵站、矿井提升机）等场景，是可靠性要求最高的多圈绝对值反馈选择。
```
